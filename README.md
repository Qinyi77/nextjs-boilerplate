# 家教管理系統專案規劃

## 專題名稱
家教預約與管理平台

## 專題簡介
開發一個雙角色（老師/學生）的家教管理系統，包含課表管理、請假系統、費用結算等功能。

## 市場定位分析
### 與既有產品差異
- 專注於「一對一家教」場景，而非補習班
- 簡化的請假與補課流程
- 季度費用自動結算
- 整合作業繳交與溝通功能

## 期望功能
### 核心功能
1. **雙角色界面**
   - 老師端：課表管理、學生資料、請假審核
   - 學生端：預約時段查看（隱私保護）

2. **請假與通知系統**
   - 常規請假（8小時前）
   - 緊急請假機制
   - 即時通知（網頁推播 + Email/簡訊）

3. **費用管理**
   - 固定課費制
   - 季度自動結算
   - 請假不計費，補課正常計費

4. **附加功能**
   - 作業繳交系統
   - 家長溝通管道
   - 臨時加課功能
   - 線上/線下課程標記
